# FocusFlow

Персональная система управления целями, планами, задачами и привычками.

## Технологии
- React 18 + TypeScript
- Vite
- Lucide React
- LocalStorage для локального сохранения данных

## Запуск локально
```bash
npm install
npm run dev
```

## Сборка
```bash
npm run build
```

## MVP
- Обзор дня и прогресс выполнения
- Список задач с добавлением и отметкой выполнения
- Привычки с ежедневными отметками
- Раздел целей
- Адаптивный интерфейс для телефона и компьютера

Данные MVP хранятся в браузере пользователя. Синхронизация между устройствами и аккаунты запланированы на следующие этапы.
